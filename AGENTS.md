# Workflow Graphify Proyek

Untuk pertanyaan arsitektur, relasi file, dampak perubahan, atau alur fitur:

1. Periksa `graphify-out/graph.json` lebih dahulu.
2. Jika graph ada, gunakan `graphify query "<pertanyaan>"` atau `graphify path` sebelum membuka banyak file source.
3. Setelah perubahan struktur penting selesai dan pengguna mengizinkan penulisan artefak Graphify, jalankan `graphify . --update`.
4. Jika graph belum ada, jangan membangunnya secara otomatis hanya untuk satu pencarian kecil; gunakan pencarian kode langsung atau minta izin karena Graphify menulis `graphify-out/`.

Panduan lengkap tersedia di `docs/GRAPHIFY.md`.
